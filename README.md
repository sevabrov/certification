# certification data

Таблиця компаній, що провозили техніку через митницю України — імпорт із Китаю
(січень–червень 2026) та експорт з України (липень 2026).

## Файли

| файл | що всередині |
| --- | --- |
| `index.html` | розмітка, стилі й уся логіка таблиці — фільтри, сортування, картки, експорт у TSV |
| `data.json` | самі дані: `periods`, `cats`, `companies`, `ct_date` |
| `*.xlsb`, `*.xlsx` | вихідні бази митних декларацій (у git не потрапляють) |

Правки по даних — тільки в `data.json`. Сторінка тягне його запитом при відкритті,
перебудовувати html не треба.

## Як подивитися локально

Подвійний клік по `index.html` не спрацює: через `file://` браузер блокує запит
до `data.json`. Потрібен будь-який http-сервер:

```sh
python3 -m http.server 8000
```

далі <http://localhost:8000/>

## Структура data.json

```jsonc
{
  "periods": [ { "key": "2026-01", "label": "Січень 2026", "flow": "imp" } ],
  "cats": [ "Автобуси", "Автовишки", "…" ],
  "ct_date": "05.09.2026",
  "companies": [ {
    "ct":    { "phones": [], "emails": [], "site": "", "person": "", "role": "",
               "acc": "", "status": "", "emp": "", "upd": "", "src": "", "conf": "HIGH" },
    "conf":  3,                  // NONE 0 · LOW 1 · MEDIUM 2 · HIGH 3 — за цим фільтр «є контакти»
    "edrpou": "12345678",
    "skip": 1,                   // необов'язкове: з фірмою не працюємо — рядок
                                 // перекреслений, з позначкою «не працюємо»,
                                 // йде в кінець списку; ховається кнопкою у фільтрах
    "name": "", "addr": "", "region": "ЛЬВІВСЬКА ОБЛ",
    "flows": ["imp"],            // imp — ввозив, exp — вивозив, обидва разом теж буває
    "cats": [], "cat_counts": {},
    "deals": 0, "usd": 0,
    "per":  { "2026-01": { "deals": 0, "usd": 0, "cats": {} } },
    "months": 1, "first": "2026-01-15", "last": "2026-01-15",
    "customs": [], "codes": [],
    "suppliers": [],             // постачальники з Китаю — для imp
    "buyers": [], "dests": [],   // покупці та країни призначення — для exp
    "items": [ { "p": "2026-01", "d": "", "c": "", "hs": "", "desc": "",
                 "usd": 0, "f": "imp" } ]
  } ]
}
```

`suppliers`, `buyers` і `dests` мають бути присутні в кожному записі — нехай
порожніми масивами: сторінка склеює їх через `join()` без перевірок.
